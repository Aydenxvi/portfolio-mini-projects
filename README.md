# Мини-проекты

Небольшие одностраничные HTML/CSS/JS-приложения без сборки и зависимостей. Каждый файл можно открыть прямо в браузере.

Открыть список со ссылками: `index.html`.

## Избранный проект: FACEFORM

**FACEFORM** — авторское Telegram Mini App для изучения пропорций лица с автоматической разметкой и ручным уточнением ориентиров. React, TypeScript, Vite, MediaPipe. Бета-версия; не медицинский инструмент.

**[Live Demo — попробовать в браузере](https://coruscating-macaron-5e62ba.netlify.app/)** · **[Открыть в Telegram](https://t.me/appolon_face_bot)**

Исходный код FACEFORM пока хранится в отдельном приватном репозитории; публичные ссылки ведут непосредственно на работающую демоверсию.

## Проекты

- **calculator.html** — калькулятор в неоновом 3D-стиле
- **todo.html** — список дел на день с прогресс-баром
- **counter.html** — простой счётчик кликов
- **converter.html** — конвертер км↔мили и °C↔°F
- **password.html** — генератор случайных паролей
- **pomodoro.html** — таймер Помодоро
- **tictactoe.html** — крестики-нолики для двух игроков
- **guessnumber.html** — игра «угадай число» (1–100)
- **currency.html** — конвертер валют (демонстрационные курсы)
- **markdown.html** — живой Markdown-превьюер (свой парсер)
- **quiz.html** — викторина с подсчётом очков
- **habits.html** — трекер привычек по дням недели
- **notepad.html** — блокнот с несколькими заметками
- **kanban.html** — канбан-доска с drag & drop
- **dashboard.html** — дашборд с графиками на демо-данных
- **tip.html** — калькулятор чаевых с разделением счёта на людей
- **stopwatch.html** — секундомер с кругами и таймер обратного отсчёта
- **palette.html** — генератор случайных цветовых палитр с копированием HEX
- **bmi.html** — калькулятор индекса массы тела со шкалой категорий

Все данные хранятся локально в браузере (localStorage), где это применимо. Конвертер валют и погодные/демо-данные используют фиксированные примерные значения, а не живые API.
